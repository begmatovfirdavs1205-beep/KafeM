# Моё Кафе

Адаптивный сайт кафе на Django с русскоязычным меню, корзиной, оформлением заказа и административной панелью Jazzmin. Заказы сохраняются в SQLite; цены и состав блюда фиксируются на момент оформления.

## Запуск в Windows через VS Code

Откройте папку проекта в VS Code и выполните команды в терминале PowerShell:

```powershell
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
Copy-Item .env.example .env
python manage.py migrate
python manage.py createsuperuser
python manage.py seed_menu
python manage.py runserver
```

Сайт откроется по адресу [http://127.0.0.1:8000/](http://127.0.0.1:8000/), панель управления — [http://127.0.0.1:8000/admin/](http://127.0.0.1:8000/admin/).

Для локального запуска переменные в `.env` можно оставить без изменений. Перед публикацией задайте длинный случайный `SECRET_KEY`, установите `CAFE_DEBUG=False` и укажите домен в `ALLOWED_HOSTS`. Папка `media` создаётся Django для фотографий, загружаемых администраторами. Демонстрационные фотографии загружаются по URL Unsplash; их можно заменить своими файлами в карточках блюд и категорий.

## Заказы и доставка

Корзина хранится в сессии браузера. Стоимость доставки — 15 сомони, бесплатно от 150 сомони; самовывоз бесплатный. Оплата — наличными при получении. После оформления клиент получает уникальную ссылку для проверки статуса. В админке можно менять статус, распечатать заказ и выгрузить выбранные заказы в CSV.

Чтобы получать уведомления о новых заказах в Telegram, заполните `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` в `.env`. Без этих параметров заказы продолжают оформляться штатно.
